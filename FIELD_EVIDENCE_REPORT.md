# Интеграция Field Evidence

## Реализация

- Подробности обращения: существующий список `selectedFields` дополнен текстовыми состояниями с цветными точками. Сопоставление по точной координате, переход к графу сохранён. Evidence читается по `requestId`, по 100 записей, следующие страницы доступны по кнопке. Отсутствующие на ещё не загруженных страницах поля не получают преждевременного состояния. После полной загрузки отсутствие свидетельства обозначается как недостаток данных.
- Подробности поля: ленивый блок «Наличие поля в ответах» после метрик покрытия. Отдельно показаны `selectedRequestCount`, `observedHits` и четыре категории. Отсутствующая координата — корректный пустой результат. Предупреждения о неполноте обращений не прибавляются к категориям поля.
- Подробности теста: в существующих строках полей оставлены `hits` и переход к графу, добавлены четыре счётчика из прежнего `/tests/{executionId}/fields`. Используется `observedCount`, без дополнительных запросов Evidence для полей и без единого статуса всего теста.

API использует существующий `requestJson` с cookie-авторизацией и проверкой DTO. Ошибки 401/403/404/422 и сети отображаются отдельно от пустого результата. Применены существующий отменяемый загрузчик и ключи контекста service/session/run/snapshot/request/field. При смене контекста старые результаты не отображаются. Исторические обращения без свидетельств не считаются доказанным отсутствием поля.

Schema Coverage, раскраска графа, сравнение прогонов, CI и навигация не изменены. Frontend не анализирует GraphQL-ответы самостоятельно.

## Контракты

Проверены read-only в репозитории [QualiMeter/GraphQL-Coverage-Proxy-Beckend](https://github.com/QualiMeter/GraphQL-Coverage-Proxy-Beckend):

- `app/evidence_analytics.py`
- `app/field_evidence.py`
- `app/api.py`
- `docs/field-evidence.md`
- `app/test_executions.py`

Используются только существующие GET endpoints. `selectedHits` и `hits` не заменяются наблюдениями. Общий DTO `observedHits` и тестовый DTO `observedCount` обрабатываются отдельно.

## Проверки

- `npm run lint` — успешно.
- `npm test` — 355 тестов, 35 файлов, успешно; из них 34 новых теста Field Evidence.
- `npm run build` — успешно. Vite сообщает предупреждение о размере основного JS chunk более 500 kB.
- `git diff --check` — успешно.

Новые проверки охватывают запрос по requestId и отмену, координаты с точным регистром, страницы по 100 полей, исторические и отсутствующие данные, четыре состояния, агрегацию, различия DTO и метрик, ошибки доступа/сети, идентичность контекста и отбрасывание запоздавших результатов, сохранение переходов к графу. UI-тесты используют серверный рендер компонентов и управляемый загрузчик; это не полный браузерный E2E-тест.

В браузере на `http://localhost:5173/` проверены раскрытие нового блока у `Product.price`, его расположение после метрик и состояние без доступа к журналу. Полная браузерная проверка реальных обращений и тестов ограничена отсутствием авторизованной сессии с нужными правами. Данные на backend не создавались и не изменялись.
