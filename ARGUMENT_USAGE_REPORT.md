# SDL корневых полей и Argument Usage

## Что реализовано

Только у полей объектных типов с модельной ролью `query` или `mutation` добавлены вкладки «Обзор» и «SDL». Поддерживаются `role` и `rootOperations`, включая пользовательские имена корневых типов. Поля обычных объектов, интерфейсов и subscription не получают новых вкладок или Argument Usage.

SDL берётся существующим `useBackendSdl` из `/api/schemas/{snapshotId}/sdl`. Условие загрузки в AnalyticsApp расширено для новых вкладок. Для старых графов без метаданных аргументов корневого поля SDL также используется, чтобы определить наличие аргументов. Объявление выбранного поля выделяется через `parse`/`print`, включая `extend type`, описания, директивы, тип и значения по умолчанию. Используется прежний CodeView. Отображение SDL обычных типов сохранено.

На вкладке «Обзор», рядом с Field Evidence, добавлен ленивый блок «Использование аргументов» только для корневых полей с аргументами. Он использует существующий GET `/api/runs/{runId}/arguments` с точными фильтрами типа и поля, cookie-авторизацией и AbortSignal. Пагинация по 100 записей позволяет загрузить более 200 аргументов. При смене поля, прогона, snapshot или service/session раскрытие и страницы сбрасываются уникальным React key; старые запросы отменяются, поздние ответы игнорируются.

Показаны пять независимых счётчиков, requestCount, тип аргумента и только факт наличия schema default. Значения аргументов и переменных не отображаются. Значения schema defaults доступны в SDL как часть объявления схемы, а не через аналитику.

Доступность `partial` сопровождается run-wide предупреждением с unavailableRequests; `unavailable` отображается как недоступная аналитика без нулевых метрик. Учтены пустой каталог, невыбранные аргументы, 401/403/404/422 и сеть. Статистика не трактуется как выполнение resolver или изменение покрытия.

## Контракты

Перед реализацией read-only проверены актуальные [docs/argument-usage.md](https://github.com/QualiMeter/GraphQL-Coverage-Proxy-Beckend/blob/main/docs/argument-usage.md) и [app/argument_usage.py](https://github.com/QualiMeter/GraphQL-Coverage-Proxy-Beckend/blob/main/app/argument_usage.py).

DTO проверяется на контекст run/snapshot/координаты, целые неотрицательные счётчики, отсутствие дублирования аргументов, сумму пяти категорий и согласованность доступности с итогами прогона. Неизвестное состояние аргумента не смешивается с недоступностью коллекции обращения.
