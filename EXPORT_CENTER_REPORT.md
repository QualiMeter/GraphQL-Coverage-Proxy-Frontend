# Единый центр экспорта

## Интерфейс

Одна кнопка «Экспорт» с иконкой скачивания размещена справа в верхней панели контекста, рядом с существующим управлением прогонами. Без выбранного прогона она недоступна. На узком экране кнопка переносится в строку действий без наложения на селекторы.

Диалог «Экспорт данных прогона» содержит CSV/JSON, пять наборов, «Выбрать всё / Снять всё», флаг текущих фильтров и одну основную кнопку. Недоступные по модели роли наборы отключены; backend остаётся окончательной проверкой прав. Покрытие явно описано как каталог полей с метриками, а не полный SDL.

В сравнении на том же месте открывается «Экспорт сравнения прогонов» без выбора обычных наборов. Экспорт доступен после успешного актуального расчёта. Изменение baseline/target/состава прогонов, снимка или категории с новым расчётом делает старый результат недоступным. Параметры пагинации сравнения в экспорт не передаются.

## API и файлы

Подключены существующие GET `/api/runs/{runId}/exports/{coverage|operations|requests|tests|test-matrix}` и POST `/api/runs/compare/export`, с `format=json/csv`.

Контракты read-only проверены в backend-репозитории: [docs/exports.md](https://github.com/QualiMeter/GraphQL-Coverage-Proxy-Beckend/blob/main/docs/exports.md), `app/export_api.py`, `app/export_data.py`, `app/export_files.py`.

Один набор сохраняется исходным файлом backend. Несколько JSON-документов объединяются в `{bundleVersion:1,runId,datasets}`; `test-matrix` получает ключ `testMatrix`. Оригинальные документы с metadata, formatVersion, filters, summary, rowCount и rows сохраняются целиком. Перед объединением проверяется принадлежность JSON к выбранным сервису, снимку, прогонам и набору.

Несколько CSV упаковываются браузерной библиотекой `fflate` в один ZIP, с файлами `coverage.csv`, `operations.csv`, `requests.csv`, `tests.csv`, `test-matrix.csv`. CSV сохраняется побайтно, включая BOM, CRLF и защиту формул backend. Аналитика на frontend не пересчитывается.

Скачивания идут последовательно. Ошибка любого набора прекращает весь экспорт и называется в сообщении. Общий лимит исходных файлов в браузере — 32 МиБ; проверяется Content-Length и фактически прочитанный поток. Повторный запуск блокируется синхронно. Смена контекста, закрытие панели и отмена прерывают запросы/упаковку; запоздавшие результаты не скачиваются. Для Blob создаётся временный URL, который освобождается после старта скачивания, временная ссылка удаляется.

Все URL относительные, cookie — same-origin, cache — no-store. POST передаёт действующий CSRF; Origin формируется браузером штатно. Имена Content-Disposition принимаются только после проверки, иначе генерируется имя. HTTP 401/403/404/409/413/422/503, сеть, неполные файлы и некорректный JSON не выдаются за успешную выгрузку. Содержимое файлов не сохраняется в localStorage и не логируется.

## Фильтры

В памяти текущего service/session/snapshot/run сохраняются актуальные серверные фильтры и состояние локальных контролов операций, журнала и расширенных контролов таблицы покрытия. Из существующего TestListView берутся фильтры тестов и матрицы. Нового хранения в localStorage нет; смена контекста сбрасывает регистр фильтров.

Coverage передаёт покрытие, границы Hits, returns, deprecated, search, typeName и соответствующую серверную сортировку. Operations — поиск имени, operationType, координату, hasErrors и сортировку. Requests — существующий JournalQuery, включая тест, операцию, координату, HTTP-код/класс, ошибки, период и сортировку, а также errorGroup. Tests/matrix — текущий ExecutionQuery. Выключение флага фильтров передаёт пустую конфигурацию; для comparison остаются выбранные прогоны и категория all.

Пагинация таблиц не ограничивает файл. Локальный AST-path и фильтры/выделение графа не выдаются за серверные ограничения; в диалоге показаны соответствующие пояснения. Для Coverage используются фильтры таблицы схемы. Фильтр типа на текущей странице сравнения также не применяется к экспорту.

## Ограничения

Защищённые Requests/Tests/Test Matrix и браузерный POST экспорта сравнения проверены контролируемыми автоматическими тестами; авторизованная браузерная сессия отсутствовала. Каждый endpoint формирует собственный согласованный документ, поэтому объединение нескольких наборов активного прогона может отражать немного разное время: исходные metadata.generatedAt сохраняются. Общий клиентский лимит 32 МиБ может потребовать сузить фильтры или выбрать меньше наборов даже при допустимом размере каждого backend-файла отдельно.

На старте ветка `feat/frontend-dashboard`, рабочая копия чистая. Изменения оставлены локально без commit/push/pull/merge/reset/PR. Backend, БД, QA, CI и production не изменялись; браузерная проверка выполняла только чтение и скачивание.
