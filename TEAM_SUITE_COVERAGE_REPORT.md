# Team/Suite Coverage во вкладке «Тесты»

## Реализация

В существующую панель фильтров добавлены два компактных селектора: Team и «Набор тестов». Каждый содержит «Все», реальные ключи из backend и «Без группы». Никаких новых страниц, основных вкладок, групповых таблиц или дополнительных панелей аналитики не создано.

Группы загружаются через GET `/api/runs/{runId}/test-coverage/groups?groupBy=team|suite&limit=100&offset=...`. Загрузчик последовательно читает все страницы с учётом X-Total-Count. Если заголовок отсутствует, продолжает до неполной страницы; первые 100 групп не становятся ограничением интерфейса. Группа backend с key=null представлена фиксированным пунктом «Без группы». Предусмотрены загрузка, отсутствие маркированных групп, ошибки и повторное чтение.

Существующий GET `/api/runs/{runId}/tests` получает teamKey/suiteKey или unassignedTeam/unassignedSuite. Выбор группы сохраняет остальные фильтры, закрывает прежнее выделение и сбрасывает offset на 0. Ключ и unassigned для одной категории взаимоисключающие. Значения ключей передаются точно; UI-кодирование не конфликтует с реальными ключами вроде `unassigned`.

Используется прежний отменяемый загрузчик: новые фильтры сразу скрывают прежние строки, поздние ответы игнорируются. Существующий контекст TestListView сбрасывает фильтры при смене сервиса/snapshot/run. Кнопка обновления тестов также обновляет каталоги групп.

В первом столбце таблицы компактной дополнительной строкой показаны Team и набор без новых столбцов. Отсутствующие или null-ключи исторических тестов отображаются как «Без группы». Количество найденных выполнений берётся из backend. Деталь, открытая по связи вне страницы, не добавляется в список вопреки выбранной группе.

Существующая сводка содержит счётчики всего прогона, а не процент группового покрытия; её область теперь явно подписана. Новая сводка или клиентский расчёт групповых процентов не добавлялись. Глобальные Schema Coverage, Field Evidence и метрики отдельных тестов сохранены. Endpoint групповых полей не запрашивается, поскольку отдельная аналитика покрытия групп здесь не нужна.

Единый центр экспорта уже получает актуальный TestListView.query. Расширенный тип запроса автоматически передаёт новые ключи и unassigned-флаги в экспорт tests и test-matrix. При выключении «Учитывать текущие фильтры» они не передаются. Дополнительных кнопок экспорта не добавлено.

## Контракты и доступ

Read-only проверены [docs/team-suite-coverage.md](https://github.com/QualiMeter/GraphQL-Coverage-Proxy-Beckend/blob/main/docs/team-suite-coverage.md), `app/test_groups.py`, `app/test_executions.py` backend-репозитория.

Используются существующие cookie-авторизация и requestJson. Группы не запрашиваются для ролей без доступа к журналу. Backend окончательно проверяет service grant. Ошибки доступа не трактуются как отсутствие групп. ExecutionOut дополнен необязательными nullable-ключами; старые ответы без них продолжают приниматься, некорректные типы отклоняются.

## Изменённые файлы

- `src/analytics/BackendTests.tsx` — подключение фильтров, каталоги групп, подписи строк, найденное количество и область сводки.
- `src/analytics/TestGroupSelect.tsx` — новый компактный селектор с состояниями загрузки/ошибки.
- `src/analytics/testCoverageModel.ts` — безопасное переключение ключа/«Без группы» и проверка выбранной детали на принадлежность группе.
- `src/analytics/testCoverage.css` — компактные адаптивные стили на переменных существующей темы.
- `src/api/testGroups.ts` — DTO/валидация групп, пагинация и загрузка всех ключей.
- `src/api/testCoverage.ts` — расширение ExecutionQuery, взаимоисключающие параметры и сериализация boolean.
- `src/api/comparisonDtos.ts`, `src/api/comparisonSchemas.ts` — совместимые поля teamKey/suiteKey в DTO выполнения и его проверке.
- `src/api/testGroups.test.ts`, `src/analytics/testGroupsUi.test.tsx` — новые API- и DOM-тесты.

## Проверки

- `npm run lint` — успешно.
- `npm test` — 459 тестов в 44 файлах, включая 27 новых тестов этой задачи.
- `npm run build` — успешно. Vite сообщает существующее предупреждение о размере основного JS chunk более 500 kB.
- `git diff --check` — успешно.

Новые тесты покрывают 205 именованных групп плюс unassigned с несколькими страницами, отсутствующий X-Total-Count, реальные ключи и оба unassigned-флага, существующие фильтры, offset=0, found count, старые DTO, ошибки 401/403/404/422, доступ по роли, смену контекста, отмену/поздние ответы, пустую выборку и передачу фильтров в оба экспортных набора. Прежние проверки Test Coverage, Field Evidence, навигации, покрытия и экспорта проходят.

Авторизованная браузерная проверка реальных списков групп не выполнялась: проверка контрактов проведена по актуальному backend-коду, UI/API-сценарии — автоматическими тестами с контролируемыми ответами.

Ветка `feat/frontend-dashboard`, на начало задачи рабочая копия была чистой. Всё оставлено локально без commit/push/pull/merge/reset/PR. Backend, QA, CI и production не изменялись; зависимости не менялись.
